# 后端是否搬迁至国内 — 实测决策报告

日期：2026-09-21 20:30（晚高峰）
测量点：本机（中国大陆）→ 各目标各 20 次采样

---

## 一、结论

**该搬。** 这是目前所有优化手段里，唯一能同时解决「延迟抖动」「并发算力」「冷启动」三件事的动作，而且**代码改动为 0 行**。

前几轮做的封面瘦身（−92%）、切歌 Blob 缓存、幂等设源，本质都在**减少请求数与字节数**；但**每个请求要交的那笔跨境税（~280ms，p90 时 ~1.1s）改不掉**，只能靠换机房。

---

## 二、实测数据

### 建连耗时（TCP + TLS 握手，20 次采样）

| 指标 | Render 新加坡 | 国内（COS 南京） | 差距 |
|---|---|---|---|
| p50 | 402 ms | 96 ms | **4.2×** |
| p90 | **1232 ms** | 126 ms | **9.8×** |
| max | 1502 ms | 141 ms | 10.7× |
| 抖动 σ | **307 ms** | 15 ms | **20×** |
| 握手失败 | 0 / 20 | 0 / 20 | — |

### HTTP 首字节（TTFB，8 次采样）

| 指标 | Render 新加坡 | 国内（COS 南京） |
|---|---|---|
| p50 | 387 ms | 108 ms |
| max | 883 ms | 210 ms |
| TCP 握手 | 181 ms | 45 ms |
| TLS 握手 | 194 ms | 48 ms |

> 注：Render 的 TTFB(387ms) 减去建连(375ms) 只剩约 12ms — **服务端处理本身很快，全是物理距离**。

### 这解释了「有时候太慢」

- 你感知的「平时还行」= p50 那 402ms
- 你感知的「有时候太慢」= **p90 那 1232ms**，纯握手就 1.2 秒，页面还没开始加载
- 抖动 σ 307ms 意味着**同一操作耗时能差 4 倍**（min 371 / max 1502）
- 一个页面要建 1 条 WebSocket + 若干次 API；连接被回收、切网、后台唤醒后都要重新交税

## 三、另外两笔账（除延迟外）

| 项目 | Render 免费版 | 国内轻量（2核2G） |
|---|---|---|
| CPU | 0.1 核 | 2 核 → **20×** |
| 内存 | 512 MB | 2 GB → 4× |
| 休眠 | 15 分钟无请求即休眠，冷启动 30–50 s | 常驻不休眠 |
| 月带宽 | 100 GB（共享） | 300–600 GB（按套餐） |

「多端同时连会卡」的真正源头就是 0.1 核。上轮加的「自己 ping 自己」保活只是在跟平台规则打游击，搬走就彻底不需要了。

## 四、全链路视角

| 环节 | 现在 | 搬迁后 |
|---|---|---|
| 前端 + API + WS | Render 新加坡（跨境 400ms+） | 国内轻量（96ms） |
| 音乐 / 封面 | COS 南京 ✓ 已在境内 | 同区，可选内网 |
| LLM（DeepSeek） | 境内 ✓ | 境内 ✓ |
| TTS（MiMo） | 境内 ✓ | 境内 ✓ |
| 定时任务 | Render 常被休眠打断 | 稳定常驻 |

**搬完后整条链路都在境内**，这也是延迟能降一个数量级的根本原因。

## 五、三条路径

### 路径 1 ⭐ 腾讯云轻量 · 国内节点（上海/南京）+ ICP 备案

| 项 | 内容 |
|---|---|
| 收益 | 建连 96ms、零抖动、2 核算力、不休眠、全链路境内 |
| 成本 | 首年秒杀 ¥68–99（2核2G3M）/ 常规约 ¥459/年；域名 ¥30–60/年 |
| 门槛 | **ICP 备案 7–23 工作日**（身份证 + 域名 + 人脸核验；服务器需包年包月 ≥3 个月） |
| 代码改动 | **0 行** |
| 备注 | 未备案期间 80/443 会被拦，但可用 `IP:8787` 自测；微信内置浏览器打开 IP 链接有被拦风险 |

### 路径 2 腾讯云轻量 · 香港节点（免备案）

| 项 | 内容 |
|---|---|
| 收益 | 当天上线；建连约 30–80ms，比新加坡好 5–10 倍 |
| 成本 | 约 ¥25–80/月 |
| 缺点 | 仍是跨境，**晚高峰仍会波动**（幅度小于新加坡）；国际带宽单价偏高 |
| 适合 | 不想等备案 / 暂无域名 / 想先试水 |

### 路径 3 不搬，只做前端分流

前端静态资源上国内 CDN，API 留 Render。

**不推荐** — 静态资源只有 100KB 且已有哈希长缓存，本就快；而 API 的 p90 1.2s 一分未省。治标不治本。

## 六、推荐执行方案

**拍板：走路径 1（国内轻量 + 备案）。**

备案等待期的过渡，二选一：

- **A（推荐）**：先买香港节点顶上当天可用 → 备案通过后迁国内。同一套代码，改 DNS 即可，无重复工作。
- **B**：在 Render 等着，备案通过后一次性切换。零额外支出，但 2–3 周内继续忍受抖动。

## 七、迁移步骤预演（约 1–2 小时工作量）

1. **买机器**：腾讯云轻量，地域选**上海或南京**（与 COS 同区），2核2G3M 起，包年包月（备案要求 ≥3 个月）
2. **装环境**：Node 22 + git + pm2
3. **部署**：clone 仓库 → 装依赖 → `vite build` → pm2 常驻 `server/entry.ts`
4. **搬环境变量**（当前 4 个，从 Render Dashboard 导出）：
   `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` / `MIMO_API_KEY` / `NETEASE_COOKIE`
   另加 `COS_LIBRARY=1` + `COS_BASE_URL`（线上现用）
5. **反代 + 证书**：nginx 反代 80/443 → 8787，certbot 免费证书自动续期
6. **域名解析**切过来，提交备案
7. **验证清单**：`/api/health`（队列 107 + llm.active）→ `/api/peek`（200）→ 封面 URL 含 `imageMogr2` → WS 连通 → `/api/dj/open` 出词 → 手机 4G 真机起播

---

## 八、遗留风险

- 备案需主体资质（个人身份证即可），周期不可控（各省管局 7–23 工作日）
- 国内轻量带宽 3–5 Mbps：音乐走 COS 直连不经服务器，占用很低；**唯一带宽消耗是 DJ 语音**（约 110KB/条），3Mbps 足够数人并发
- 迁移后需重新验证主人设备 bond（HMAC 密钥为常量，不随部署变化，预期无需重绑）
