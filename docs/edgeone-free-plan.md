## 一、需求与约束

| 需求 | 说明 |

| 微信分享 | 生成分享链接（`https://<域名>/share/xxx`），微信内打开即听，无需装 App |

| 版权合规 | 不直接分发音乐流（方案文档约定），听众端听 DJ 解说词 TTS + 看字幕 |

**EdgeOne 免费版能力核对**（2026-08 公开信息）：
| 能力 | 免费版 | 说明 |

## 二、总体架构（适配当前 Node 项目）

```
┌────────────────────────────┐         HTTP/WS 推送          ┌──────────────────────────────────┐
│  电脑端 ai-radio（主播端）   │ ──────────────────────────►  │  EdgeOne Pages + Functions（云端） │
│                            │   {type:"subtitle",en,zh}    │                                  │
│  Node 后端 (Express+ws)    │   {type:"track",name}        │  /api/push     接收 DJ 推送 → KV   │
│  ├─ 网易云音乐 API(本地)    │   {type:"status",listeners}  │  /ws           听众广播+连接管理    │
│  ├─ DJ 话术/天气/趣闻      │ ◄──────────────────────────  │  /api/episode/:id 回放数据         │
│  ├─ node-edge-tts(解说合成) │        听众数 / 心跳          │  /share/:id   微信落地页(OG Meta)  │
│  └─ 新增 edgeone-push.ts   │                              │  KV: ep:{id}:history（字幕时间轴） │
│     （每次说话/切歌自动推送） │                              │  KV: ep:{id}:now（当前曲目）       │
└────────────────────────────┘                              └──────────────┬───────────────────┘
                                                                           │ WebSocket (wss://)
                                                          ┌────────────────▼───────────────────┐
                                                          │  EdgeOne Pages 前端（复用现有组件）   │
                                                          │  /live           直播页（字幕+TTS朗读）│
                                                          │  /episode/:id    回放页（时间轴）      │
                                                          │  /share/:id      微信分享落地页        │
                                                          └────────────────────────────────────┘
                                                                           │
                                                          ┌────────────────▼───────────────────┐
                                                          │  微信 / 手机浏览器（无需同网络）       │
                                                          │  - 点击分享链接 → 实时字幕 + 解说朗读  │
                                                          │  - 浏览器 SpeechSynthesis 朗读（零成本）│
                                                          └────────────────────────────────────┘
```

**核心思路**：EdgeOne Pages Functions 是无状态的边缘计算（无法常驻 Node 后端），所以：
- **电脑端 = 内容生产者**（生成字幕/解说/曲目信息，音乐在电脑本地播放）
- **EdgeOne = 云中枢**（接收电脑推送 → 写 KV + 广播给所有听众）
- **手机/微信 = 纯听众**（WebSocket 接收字幕，浏览器 TTS 朗读解说词）

## 三、音乐版权处理（两个可选方案）

### 方案 A：只听解说词（推荐，免费版稳妥）
- 电脑端照常播放完整音乐（本地音箱）
- 手机/微信听众端：**看滚动字幕 + 浏览器朗读 DJ 解说词**（SpeechSynthesis，零成本）
- 听众想听音乐 → 自行打开网易云搜索（链接给出）
- 优点：零版权风险、零流量成本、EdgeOne 免费版完全够用

### 方案 B：EdgeOne 代理音频流（进阶，需实测）
- EdgeOne Functions 增加 `/api/audio/:id` 代理网易云音频直链
- 风险 ①：免费版 Functions 单次响应体大小限制（MP3 3-5MB，需实测是否被截断）
- 风险 ②：网易云防盗链（部分直链校验 Referer，代理需改写请求头）
- 风险 ③：版权风险（方案文档明确约定"不传输音乐流"）
- 建议：**先按方案 A 上线，方案 B 作为 P2 实验**（单独测一条直链能否穿透）

## 六、风险与降级

| 风险 | 影响 | 缓解 |
|------|------|------|
| KV 最终一致性 60s | 回放页数据可能延迟 | 直播广播走 WS 内存不受影响；回放页接受 60s 内更新 |
| 免费版 Functions 响应体大小 | 音频代理可能失败（方案 B） | 方案 A 无此问题 |
| 微信 X5 内核 WebSocket/SpeechSynthesis 兼容 | 部分机型朗读失败 | 代码加能力检测 + 降级为"仅显示字幕" |
| 电脑关机/断电 | 直播间离线 | `/live` 页显示"主播暂未开播"占位 + 心跳超时判断 |
| 预览域名 3h 过期 | 链接失效 | 阶段一必须完成自定义域名绑定 |
