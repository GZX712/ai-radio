## 下一步：上传到 COS（需要腾讯云密钥）

项目里**没有保存** SecretId/SecretKey（安全），密钥只能由你提供。三种方式：

### 方式 A · 你自己跑（推荐）

**1. 拿密钥**

腾讯云控制台 → 访问管理 CAM → API 密钥管理 → 新建密钥

- SecretId 形如 `AKIDxxxxxxxxxxxxxxxx`
- SecretKey **只在创建时完整显示一次**，务必先存好

> 💡 更稳的做法：用**子账号**（CAM 用户）密钥，只授权桶 `ai-radio-library-1463614289`，
> 万一密钥外流，损失止于这一个桶。完整步骤见下方「附录：新建子用户密钥」。

#### 附录：新建子用户密钥（3 步）

1. **建子用户**：控制台 → 访问管理 CAM → 用户 → 用户列表 → 新建用户
   （注意：「快速新建用户」只给控制台登录，**不含 API 密钥**，需按下面第 2、3 步补齐）
2. **授权**：点进该用户 → 「权限」标签 → 关联策略 → 搜索 `QcloudCOSFullAccess`
   → 勾选 → 确定
   - ✅ 只勾 **`QcloudCOSFullAccess`**（COS 全部读写，够用，且只影响 COS 范围）
   - ❌ 别勾 `AdministratorAccess`（= 主账号全权限，等于把整个腾讯云的钥匙交出去）
   - ❌ 别勾 `ReadOnlyAccess`（只读，文件传不上去）
   - 授权后**立即生效**，不需要额外操作；右侧「已选择」显示 1 条即成功
3. **建密钥**：控制台 → 访问管理 CAM → 用户 → 用户列表 → 点用户名 → 用户详情页
   → 「**API 密钥**」标签 → 「新建密钥」
   → 弹窗里复制 **SecretId**（`AKID…`）与 **SecretKey**（32 位随机串）
   → ⚠️ **SecretKey 只在生成时显示这一次**，关掉就再也看不到，漏了只能删掉重建
   - 找不到「API 密钥」标签时的备用路径：
     ① 用户详情页 → 「用户信息」→ 往下找「API 密钥」区块 → 新建密钥
     ② 若提示需开启「编程访问」→ 用户详情 → 「用户信息」→ 访问方式 → 勾上「编程访问」后重试

**常见误区（本项目实际踩过）**

| 看到的东西 | 实际是什么 | 能用吗 |
|---|---|---|
| 「快速新建用户」页里的**密码**（如 `Jk30xJB`） | 控制台**登录密码** | ❌ 不是密钥 |
| `SecretId: -` / `SecretKey: -` | **密钥尚未生成** | ❌ 空 |
| 「权限信息」显示 `共 0 条` | **未授权** | ❌ 即使有密钥也会被 COS 拒绝 |
| 密钥文件里两行写反 | SecretId 必须在第 1 行 | ❌ 报 `InvalidAccessKeyId` |

**⚠️ 为什么「新建密钥」总会跳转？**

走错入口了。`console.cloud.tencent.com/cam/capi`（左侧「API 密钥管理」）是**主账号**的页面，
点「新建密钥」会弹「不建议使用主账号 API 访问密钥」。该弹窗里：

- 蓝色按钮「**切换使用子用户访问密钥**」—— **不是创建密钥**，而是把你送到「新建用户」页
  （地址栏会变成 `/cam/user/userType`），所以看起来像在打转
- 灰色按钮「**继续使用**」默认**不可点**，需先勾选弹窗下方的复选框
  （"我已了解使用主账号 API 访问密钥的风险"）
- 想给子用户建密钥，**别从这个入口进**：左侧 → 用户 → **用户列表** → 点用户名
  （蓝色链接）→ 详情页 → 「**API 密钥**」标签 → 新建密钥
- 若确实要走主账号（快一步，但权限是全账号级）：勾选复选框 → 「继续使用」→ 复制两个值

**⚠️ 在「用户列表」点用户名称没反应？**

官方路径是「用户列表 → **单击目标子用户名称** → 用户详情页 → 「API 密钥」页签 → 新建密钥」。
若点击无响应，按顺序排查：

1. **控制台会话超时**（最常见）—— 腾讯云控制台闲置后会"假死"，点了没反应 → `Ctrl + F5` 硬刷新，必要时重新登录
2. **点的位置不对** —— 只有**用户名称文字本身**是链接；点行首复选框、格子空白处都不会跳转
   （行首复选框只是"选中"，底部会显示"已选 N 项"，不产生跳转）
3. **换入口** —— 同一行最右侧「**更多操作 ▾**」里看有没有「查看详情」
4. **浏览器插件拦截** —— 用**无痕窗口**重新打开控制台试
5. **兜底** —— 走主账号路径（见上一条）

**2. 把密钥写进一个文件**（放仓库外，例如 `D:\_cos_key.txt`），两行：

```
AKIDxxxxxxxxxxxxxxxx
SecretKeyxxxxxxxxxxxxxxxxxxxxxxxx
```

**3. 执行**

```bash
cd D:\Workspace\AI工作空间仓库\ai-radio
python tools\cos_upload_incremental.py --from-file D:\_cos_key.txt
```

> 桶名与地域已有默认值（`ai-radio-library-1463614289` / `ap-nanjing`），无需再传。
> 也支持老写法直接传参：`python tools/cos_upload_incremental.py <SecretId> <SecretKey>`

**4. 跑完删掉密钥文件**
